# 技术知识点汇总

## 一、网络基础

1. TCP 三次握手建立连接：客户端发送 SYN，服务端回应 SYN+ACK，客户端再发送 ACK。
2. TCP 四次挥手释放连接：主动关闭方发送 FIN，对方回应 ACK，随后发送 FIN，最后 ACK。
3. HTTP/2 在单个连接上并行传输多个请求，降低队头阻塞。
4. QUIC 基于 UDP 实现可靠传输，减少握手往返次数。

## 二、操作系统

1. 进程是资源分配的基本单位，线程是调度的基本单位。
2. 虚拟内存通过页表把虚拟地址映射到物理地址。
3. 页面置换算法常见的有 LRU、FIFO 与 Clock。
4. 文件系统通过 inode 记录文件的元数据与数据块位置。

## 三、数据库

1. B+ 树索引把数据存放在叶子节点，适合范围查询。
2. 事务的 ACID 分别指原子性、一致性、隔离性与持久性。
3. 隔离级别从低到高为读未提交、读已提交、可重复读、串行化。
4. 主从复制通过 binlog 把主库变更同步到从库。
