# 字节面试题与面经

每道题后附参考答案，答案以有序列表展开。

## 面试题

### Q: 什么是 Agent 的核心组成？

**参考答案：**
1. 系统上下文：把所有相关上下文拼进 prompt
2. 工具调用：让模型可以调用外部函数完成动作
3. 任务分解：把复杂目标拆成可执行的小步骤
4. 记忆机制：保存多轮对话中的关键信息

### Q: 什么是 RAG 的基本流程？

**参考答案：**
1. 文档切分：把长文档拆成适合检索的片段
2. 向量化：把片段编码为向量并写入索引
3. 召回：根据查询检索最相关的若干片段
4. 生成：把召回内容与问题一起交给模型作答

### Q: 如何设计一个客服 Agent？

**参考答案：**
1. 意图识别：先判断用户诉求属于哪一类
2. 知识检索：从知识库取出对应的标准答案
3. 兜底转人工：置信度不足时及时转接人工
4. 满意度回访：会话结束后收集用户反馈

### Q: 如何评估 RAG 的效果？

**参考答案：**
1. 召回率：相关片段是否被检索出来
2. 准确率：生成答案是否与原文一致
3. 完整性：答案是否覆盖问题的关键点
4. 时延：端到端响应是否满足体验要求

### Q: 如何抑制模型幻觉？

**参考答案：**
1. 提供可靠上下文：让模型基于原文作答
2. 要求引用来源：输出时标注依据片段
3. 设置拒答策略：证据不足时明确拒答
4. 后置校验：对关键结论做规则或人工复核

### Q: 如何做 Prompt 版本管理？

**参考答案：**
1. 版本编号：每次变更生成独立版本记录
2. 灰度发布：按流量比例逐步放量验证
3. 指标监控：对比新旧版本的线上指标
4. 快速回滚：异常时一键切回稳定版本

### Q: 如何设计多租户隔离？

**参考答案：**
1. 数据隔离：按租户划分独立的存储空间
2. 计算隔离：限制单租户的并发与算力配额
3. 权限隔离：租户之间不可互相访问资源
4. 审计隔离：操作日志按租户独立留存

### Q: 如何设计工具调用失败重试？

**参考答案：**
1. 错误分类：区分可重试与不可重试错误
2. 退避策略：采用指数退避避免雪崩
3. 最大次数：设置重试上限并记录原因
4. 降级路径：重试耗尽后返回兜底结果

### Q: 如何设计离线评测集？

**参考答案：**
1. 场景覆盖：覆盖高频与长尾业务场景
2. 标注规范：统一标注口径与质量标准
3. 版本管理：评测集随业务演进持续更新
4. 基线对比：保留历史基线便于回归比较

### Q: 如何做成本控制与限流？

**参考答案：**
1. 用量计量：按租户与接口统计资源消耗
2. 分级限流：不同套餐设置不同速率上限
3. 缓存复用：命中缓存的结果不再重复计算
4. 异常告警：用量突增时及时通知负责人
