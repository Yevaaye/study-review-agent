# 高频面试新题 - 2025

以下是今年高频出现的新题，按主题分组。

## 大模型基础

### Q: 什么是 Context Engineering？

答案：Context Engineering 是指对进入模型上下文的信息进行选择、组织与压缩的工程实践。

### Q: 什么是 Function Calling？

答案：Function Calling 是模型根据工具描述生成结构化调用参数的能力。

### Q: 什么是 MoE 架构？

答案：MoE 是混合专家架构，通过路由网络把 token 分发给部分专家计算。

### Q: 什么是 KV Cache？

答案：KV Cache 缓存历史 token 的键值向量，避免自回归解码时重复计算。

## 应用工程

### Q: 什么是 RAG 的召回漂移？

答案：召回漂移指知识库更新后，同一查询的召回结果发生非预期变化。

### Q: 什么是 Agent 的反思循环？

答案：反思循环指 Agent 对自身输出进行评估并据此修正的迭代过程。

### Q: 什么是结构化输出约束？

答案：结构化输出约束指通过语法或模式限制模型输出符合既定结构。

### Q: 什么是提示词注入防护？

答案：提示词注入防护指识别并阻断外部内容对系统指令的覆盖尝试。
