# 核心概念详解与参考答案

按概念逐条整理，每条附简要参考答案。

## 大模型核心概念

### Q1: 什么是 Tokenizer？

答案：Tokenizer 负责把文本切分为模型可处理的 token 序列。

### Q2: 什么是 Embedding？

答案：Embedding 把离散对象映射为连续向量，用于语义计算与检索。

### Q3: 什么是 Attention？

答案：Attention 通过查询与键的点积计算权重，对值进行加权聚合。

### Q4: 什么是 LayerNorm？

答案：LayerNorm 对单样本的特征维度做归一化，稳定训练过程。

### Q5: 什么是 Residual Connection？

答案：残差连接把输入直接加到子层输出上，缓解深层网络梯度消失。

### Q6: 什么是 Dropout？

答案：Dropout 在训练时随机置零部分神经元，起到正则化作用。

### Q7: 什么是 Learning Rate Warmup？

答案：学习率预热在训练初期逐步提升学习率，避免早期震荡。

### Q8: 什么是 Gradient Clipping？

答案：梯度裁剪限制梯度范数上限，防止梯度爆炸。

### Q9: 什么是 Mixed Precision？

答案：混合精度在训练中混用低精度与高精度计算，降低显存占用。

### Q10: 什么是 Checkpointing？

答案：梯度检查点用计算换显存，只保存部分中间结果并在反向时重算。

### Q11: 什么是 Beam Search？

答案：束搜索在解码时保留多个候选序列，提升生成质量。

### Q12: 什么是 Temperature？

答案：温度参数调节输出分布的平滑程度，影响生成的随机性。

### Q13: 什么是 Top-p Sampling？

答案：核采样从累积概率达到阈值的候选集合中采样。

### Q14: 什么是 Perplexity？

答案：困惑度衡量模型对文本的预测难度，数值越低通常越好。

### Q15: 什么是 LoRA？

答案：LoRA 通过低秩分解注入可训练参数，实现高效微调。

### Q16: 什么是 QLoRA？

答案：QLoRA 在量化基座上进行 LoRA 微调，进一步降低显存需求。

### Q17: 什么是 RLHF？

答案：RLHF 用人类偏好训练奖励模型，再以强化学习优化策略。

### Q18: 什么是 DPO？

答案：DPO 直接用偏好对优化策略，跳过显式奖励模型。
